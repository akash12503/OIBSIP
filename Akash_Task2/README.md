
# BMI Calculator - Python Internship Task 2

## Project Overview
A beginner-level Python program that calculates
Body Mass Index (BMI) from weight and height.

## Features
- Accepts weight in kilograms
- Accepts height in metres
- Calculates BMI
- Displays an adult reference category
- Validates non-numeric and non-positive inputs

## Technologies Used
- Python 3
- Built-in Python modules

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   python bmi_calculator.py

## Testing
Tested with valid measurements, zero values,
negative values, and non-numeric input.

## Note
This is an educational programming project.
BMI categories are general adult references and
are not a medical diagnosis.
